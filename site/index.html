Four pillars

Speed, ratio, security and resilience — no compromises.

Every file is split into blocks, processed in parallel across every core, and written through a pipeline that never stops. Corruption is an incident — not a loss.

Codec 01 · speed

Zstandard — compression at memory speed

Facebook's Zstd chews through your files at gigabytes per second on the fast tier while the engine fans blocks out across all your CPU cores. Decompression runs near memory bandwidth, so archives open as fast as the disk allows.

zstdblock-parallelmulti-core1.5 GB/s class
Codec 02 · ratio

LZMA2 — the maximum squeeze

When every byte counts, LZMA2's dictionary-driven compression digs deeper than anything in the legacy world — the same ratio engine that made 7-Zip famous, without the 20-year-old shell around it.

lzma2max ratioper-block
Security

Authenticated, end to end

Passwords become keys through Argon2id, the memory-hard winner of the password-hashing competition — then every block is sealed with XChaCha20-Poly1305, so tampering is detected the instant it happens.

argon2idxchacha20gcm-tag
Resilience

Recovery volumes that heal

Flip some bits, lose part of a download — Reed–Solomon parity in a sidecar .nvol reconstructs the missing bytes, encrypted or not.

reed-solomon.nvolrepair
Design

Indexed by the footer

Metadata lives in a smart footer, not a header — so listing and extracting a single file never means scanning a multi-gigabyte archive sequentially.

footer indexinstant list

Security model

Your data, sealed in layers

Three independent layers protect the archive — a slow, expensive key derivation that laughs at GPUs, an authenticated cipher that catches every byte flipped, and parity that puts the bytes back.

Layer 01

Argon2id key derivation

Memory-hard by design — brute-forcing a password costs real gigabytes and real seconds per guess, which is exactly what makes GPU farms useless against you.

memory-hardphc winner
Layer 02

XChaCha20-Poly1305

An authenticated stream cipher with a 192-bit nonce — random per block, so encryption never leaks patterns, and every block carries a tamper-proof tag.

192-bit noncepoly1305 tag
Layer 03

Reed–Solomon parity

Generate .nvol recovery volumes at create time; repair a corrupted archive even when it's encrypted — the parity rebuilds bytes without ever decrypting them.

repairencrypted-safeverify
